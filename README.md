# ADMorandum

一個普通的備忘錄程式/An ordinary memo program

# 目錄/Table of contents
- [功能](#功能)
- [Function](#Function)

# 功能
1. 支持畫筆、尺子、橡皮擦等
2. 支持換顏色
3. 支持鍵盤輸入文件
4. 支持用手記錄(默認)

# Function
1. Support brushes, rulers, erasers, etc.
2. Support color change
3. Support keyboard input documents
4. Support hand recording(by default)
